 # 🛒 D-Mart Sales Analysis & Dashboard 
📌 Project Overview

This project is an Excel-based D-Mart Sales Analysis and Dashboard created to analyze retail sales data and generate useful business insights.

The project covers data cleaning, Excel formulas, KPI calculations, Pivot Tables, Pivot Charts, and an interactive dashboard.

The main goal is to understand sales, profit, customer behavior, product performance, and regional performance using Excel

🎯 Project Objectives
 1). Analyze overall sales performance
 2). Calculate important business KPIs
 3). Identify top-performing products
 4). Analyze sales and profit by region
 5). Understand customer purchasing patterns
 6). Analyze payment and shipping methods
 7). Identify returned orders
 8). Create an interactive Excel dashboard
 9). Generate useful business insights from raw data
